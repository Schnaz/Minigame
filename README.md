# Minigame
https://schnaz.github.io/Minigame/
>### Astroid Miner
>the time is ticking. Break all the asteroids within a minute to win and
>lock in your score. Collecting the rare traingular ore can net you some extra time!
>#### Controls
>- used W to apply thrust, S to apply brakes, and A & D to steer
>- spacebar fires a powerful bullet (you can only have one bullet on screen at a time)
>- click to teleport, becoming incorporeal for a second (but also unable to shoot!)
>#### Winning and Losing
>- break down the asteroid to win the game and lock in your time as score.
>- if time hits zero you lose.
>- getting hit by an asteroid will activate sheilds and destroy the asteroid
>- you cannot shoot nor collide with astroids for a while after the sheild is up
>- bigger asteroids give a longer time penalty.
>- the tiniest asteroids recover an extra second if you collect them.
