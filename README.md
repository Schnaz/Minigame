# Minigame
https://schnaz.github.io/Minigame/

Astroid Miner
-the time is ticking. 
-break down the asteroid to win the game.
-the remaining time is the score.
-if time hits zero you lose.
-getting hit by an asteroid will cause you to lose time.
-if score drops below zero, you lose

-you can only have one bullet on screen at a time, but otherwise there is no restriction on fire rate.


Shapes:

ship

-bullet
-blast

-octagon
-hexagon
-pentagon
-diamond
-triangle
