# Minigame
https://schnaz.github.io/Minigame/
>### Astroid Miner
>the time is ticking.
>#### Controls
>- used W to apply thrust and A & D to steer
>- space fires a powerful bullet (you can only have one bullet on screen at a time)
>#### Winning and Losing
>- break down the asteroid to win the game and lock in your time as score.
>- if time hits zero you lose.
>- getting hit by an asteroid will activate sheilds and destroy the asteroid
>- you cannot shoot nor collide with astroids for a while after the sheild is up
>- bigger asteroids give a longer time penalty, while the tiniest asteroids have almost no penalty at all.
